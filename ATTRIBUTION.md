# Attribution and publication policy

The original Pacman AI projects were developed at **UC Berkeley**. The core
projects and autograders were primarily created by **John DeNero** and
**Dan Klein**. Student-side autograding was added by **Brad Miller**,
**Nick Hay**, and **Pieter Abbeel**.

Reference: [UC Berkeley Pacman AI](http://ai.berkeley.edu).

The supplied project notice permits educational use or extension provided
that solutions are not distributed or published, original notices are
retained, and attribution is given to UC Berkeley.

This public-facing repository intentionally includes **documentation only**:
no source code, solution code, or autograder test fixtures from the course
archive. It does not claim ownership of the UC Berkeley game engine.
